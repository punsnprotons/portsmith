# Examples and evidence

## Run the included example

```sh
npx --yes --package=portsmith-workbench@alpha portsmith-demo
```

A table filter becomes catalog search. The authored proposal makes the five declared function cases pass and retains existing tests. Add `--install-browser` for the Chromium search/reset checks. No model key is required. [Recording and reproduction](demo.md) · [Step-by-step walkthrough](first-transfer.md).

## Historical real-repository trials

These reports record controlled trials, pinned upstream revisions and scoped checks. They are not a turnkey public benchmark suite; their raw local archives are not distributed. Read each report's limitations before drawing conclusions.

| Trial area | Evidence and limitations |
| --- | --- |
| Real repository transfers and browser checks | [Validation index](validation.md) |
| More complex apps and Rea-assisted comparisons | [Comparison scope](rea.md) |
| New package imports: jsondiffpatch → drawDB | [Package import benchmark](benchmark-packages.md) |
| Dependency provisioning and discovery | [Automatic setup](automatic-setup.md) |

The Rea-assisted trials use Rea for analysis evidence and Portsmith's shared declared checks. They are not an independent comparison of unrestricted coding agents, nor evidence of general reliability parity.

## Share a transfer

[Open a transfer report](https://github.com/punsnprotons/portsmith/issues/new?template=transfer.yml) with the feature, source/target revisions, what passed, what failed and what you had to do manually. Public reproductions and failed cases are both useful. Remove credentials, private code and local paths before sharing artifacts. A small reproducible example is more useful than an entire run directory.
